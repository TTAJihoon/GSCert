서버 관리 콘솔

임베딩 (유사 시험 조회)

테스팅 에이전트의 유사 시험 조회 기능을 위해 embed_db 명령으로 reference.db에 벡터 임베딩을 생성합니다.
인증획득목록 DB가 갱신된 후 실행하세요.

ECM 인증획득목록 동기화

ECM에 접속하여 인증획득목록 엑셀 파일을 다운로드하고 전처리 후 DB에 적재합니다.
기준 월요일(예: 20260511)을 입력하면 해당 주차를 수동 갱신합니다. 비워두면 최신 주차로 자동 처리합니다.

Google Sheets 동기화

Google Sheets에서 신규 프로젝트 데이터를 가져와 로컬 SQLite DB(ecmlist.db)에 추가합니다.
2153행부터 마지막 행까지 DB에 없는 프로젝트번호만 삽입합니다.

다운로드 검토 워커

ECM 산출물 다운로드 워커를 시작합니다(서버 HTTP 직접연동).
이미 실행 중이면 중지 후 다시 시작하세요.
