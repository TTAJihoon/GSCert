# main/static

## 역할

웹 화면에서 사용하는 CSS, JavaScript, 이미지 파일을 보관한다.

## 하위 폴더

| 폴더 | 설명 |
| --- | --- |
| `css` | 화면별 스타일 파일을 보관한다. |
| `scripts` | 화면별 JavaScript 파일을 보관한다. |
| `images` | 아이콘, 배경, 화면 카드 이미지 등을 보관한다. |

## 주의사항

- 화면별 CSS와 JS는 가능하면 파일명을 화면 이름과 맞춘다.
- mock UI용 정적 파일은 실제 API 연결 단계에서 계속 사용할지, 분리할지 재검토한다.
