# main/static/css

## 역할

화면별 CSS 파일과 기능 영역별 CSS 폴더를 보관한다.

## 주요 파일

| 파일 | 설명 |
| --- | --- |
| `index.css` | 기존 메인 화면 스타일이다. |
| `header.css` | 공통 헤더 스타일이다. |
| `review/ecm_download_review.css` | ECM 제출물 자동 검사 mock UI 스타일이다. |
| `genspark.css` | genspark 화면 관련 스타일이다. |
| `helpbtn.css` | 도움말 버튼 스타일이다. |

## 하위 폴더

| 폴더 | 설명 |
| --- | --- |
| `testing` | testing 영역 화면의 CSS를 보관한다. |
| `certy` | certy 영역 화면의 CSS를 보관한다. |
| `review` | review 영역 화면의 CSS를 보관한다. |

## 주의사항

- 업무용 화면은 정보 밀도와 가독성을 우선한다.
- UI 요소가 겹치거나 버튼 텍스트가 넘치지 않도록 고정 폭과 반응형 제약을 함께 둔다.
