# 기대값 표시 문구 전체 매핑

## 기준

- 대상 화면: `/download-review/` 규칙별 점검 결과 상세 팝업
- 대상 컬럼: `기대값`
- 번호는 후속 수정 지시용 고정 ID입니다. 항목을 제외하거나 다른 항목에 통합해도 번호는 유지합니다.
- `{project_number}`, `{company}`, `{product}`, `{version}`, `{pl}`, `{start_date}`, `{end_date}`, `{wd}` 등은 실제 프로젝트 값으로 치환됩니다.
